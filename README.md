# Windows Server 2022 - Lab
Contiene una bitácora detallada de entrenamiento acerca de la configuración y administración de Windows Server 2022.

Actualmente el contenido esta basado en el Controlador de Dominio de Active Directory.
El objetivo de este repo es compartir configuraciones y conceptos de sistema WS de una manera escalonada que sirva como un tutorial una base de conocimiento a la cual recurrir.

Algo interesante es que a medida que vamos avanzando por lo temas surgen algunos desafios que se van superando, a decir verdad creo que esta es la parte más valiosa.
